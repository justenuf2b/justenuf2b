Obsidian ↔ WSL Real-Time Sync

Problem: Files created in WSL not visible in Obsidian (Windows app), need bi-directional sync
Solution: Hybrid change detection using Unison sync engine. WSL side uses inotifywait for instant detection; Windows side uses polling (NTFS doesn't support inotify). Per-profile cooldown prevents sync storms when editing. 10-second detection latency, automatic backups (5 versions), conflict resolution (prefer newer). Handles multiple project folders concurrently.
WSL: /home/ryan/[project]/ ←→ Windows: Obsidian Vault/99_wsl_projects/[project]/ [Unison sync engine with hybrid change detection] WSL: inotifywait | Windows: polling (NTFS limitations)

Tech Stack:

  • Unison 2.53.x (bi-directional sync)
  • inotify (WSL change detection), polling (Windows side workaround)
  • Per-profile cooldown (prevents sync storms)
  • Automatic backups (5 versions retained)

Challenges Solved:

  • Windows filesystem doesn't support inotify, so used hybrid approach
  • Symlinks don't work across WSL/Windows boundary, so used Unison instead
  • Conflict resolution (prefer newer file)
  • NTFS permission compatibility (perms=0, fat=true)

Human Impact (Technology × Process × Enablement):

Technology: Solves cross-platform friction invisibly; tools work together seamlessly
Process: 10-second sync enables natural workflow without "save and transfer" interruptions
Enablement: Work in best tool for each task; system handles coordination
Result: Eliminates context switching overhead. Makes it safe to work across environments.

Architecture Philosophy

Guided by five core principles from consulting methodology:

1. Make it safe to learn - Design systems that encourage experimentation without fear of breaking things

2. Default to clarity - Business-first technology decisions; every technical choice traces to business outcome

3. Measure what matters - Quantify outcomes that executives care about (time, cost, capacity)

4. Communicate early and often - Knowledge transfer built-in; stakeholder visibility throughout

5. Remove friction - Modern stack, proven tools; automation that reduces cognitive load

Common Patterns

  • Queue-based processing: Decouple triggers from execution, enable retry logic
  • Systemd automation: Background services, scheduled tasks, auto-restart on failure
  • File-based triggers: inotify monitoring → event-driven processing
  • Human-centered AI: Augment capability, not replace judgment; transparency builds trust
