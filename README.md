# justenuf2b starter site

This repository contains your initial site files ready for Git-based publishing (Cloudflare Pages, Netlify, Vercel, or GitHub Pages).

## Structure
```
./
  Headshot.jpg
  index.html
```

## Getting Started
1. Initialize git:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   ```
2. Push to GitHub and link your host (Cloudflare, Netlify, etc.).
3. Publish automatically on every commit.

## Local Preview
```bash
python3 -m http.server 8080
```
